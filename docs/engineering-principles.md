# Engineering Principles

This repository follows the public portfolio standard used across Abdulelah Alkhathami's flagship AI projects.

## Principles

- Keep public claims factual, conservative, and easy to verify.
- Explain architecture before presenting implementation details.
- Separate prototype behavior from production-ready behavior.
- Make optional services, environment variables, and failure modes explicit.
- Optimize reviewer experience: quick overview, clear setup, diagrams, and limitations.

## Applied Here

- Portfolio facts are centralized in typed data modules.
- Project pages, metadata, and assistant responses share the same source of truth.
- The assistant is constrained to portfolio context instead of acting as a general chatbot.
- Contact and model-provider integrations are optional and documented.
